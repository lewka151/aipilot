# Десктоп-агент AIPilot

Этот документ лежит в корне репозитория приложения (`H:\projects\ai`). Он **не** уходит в промпт сам по себе.

Приложение — точка доступа к диску, консоли и SSH. Чат моделей и браузер живут на сайте `/ai` и во вкладках Qwen/DeepSeek со скриптами Violentmonkey. Десктоп не встраивает CEF и не оркестрирует диалог.

## Поток команды

1. На `/ai` модель предлагает файл / run / ssh. Сайт кладёт запись в `GET /api/aipilot/commands/pending`. Десктоп шлёт `X-AIPilot-Device-Id`; сервер отдаёт только команды проектов, привязанных к этому ключу (папки сохраняли на этом ПК).
2. Агент после входа опрашивает очередь, подтягивает проект (`GET /api/aipilot/projects` + секреты SSH с `X-AIPilot-Client: desktop`) и исполняет только проекты с совпадающим `device_id` и абсолютными папками.
3. Пути только `rel` или `alias/rel` внутри корней проекта. `..` и `C:\` — отказ.
4. `run` и `ssh_exec`: эвристика `CodeRunService.denyReason`, затем DeepSeek через сайт-bridge (`POST /docs/prompt` role `safety_review`, job `provider=deepseek`, `chatId` проекта). Нет `APPROVED` — не запускать. Нужна открытая вкладка chat.deepseek.com со скриптом.
5. Результат: `POST /commands/{id}/ack` с `result` / `error` / `exit_code`. Если есть `RUN_ID`, на сайте появляется шаг `provider=aipilot`, `phase=aipilot_exec`.

SSH только если `alias` есть в `servers` проекта. Процессы python/PowerShell режутся по таймауту (~120 с) и destroy после завершения.

## Окно

Компактное (~440×560), без maximize. Шапка: бренд, кружок API (зелёный — сессия и пинг, серый — нет входа, красный — сеть), свернуть, закрыть в трей. Главный экран — карточки очереди. «Настройки» / «← Назад». Ссылка на сайт открывает `{apiBase}/ai` в системном браузере.

Настройки: сервер, аккаунт, приложение (автообновление, автозапуск Windows, старт в трее, логи). Проекты — папки и SSH с сайта, не локальный скан как правда.

Присутствие: `POST /api/aipilot/bridge/register` `{ provider: "aipilot", version, ready }` каждые ~10 с. На `/ai` третья плашка «AIPilot — онлайн / нет связи».

## Автозапуск Windows

Чекбокс создаёт ярлык `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\AIPilot.lnk` на `AIPilot.exe --tray`. Старт из автозагрузки не показывает окно, пока не «Открыть» из трея.

## Чего агент сознательно не делает

- Не открывает chat.qwen.ai / chat.deepseek.com внутри себя.
- Не собирает промпты Qwen/DeepSeek и не ведёт in-app чат.
- Не пишет файлы вне корней проекта и не ходит по SSH без алиаса из настроек проекта.
